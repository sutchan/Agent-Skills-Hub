Agent Skills Hub 是什么？
Agent Skills Hub 是一个开源、免费、纯静态的 AI Agent 技能（Skill）目录。技能按 SKILL.md 规范组织，站点提供分类浏览、关键词搜索、标签筛选、投票收藏与技能详情，界面支持简体中文、繁体中文和英语。
Agent Skills Hub 是什麼？
Agent Skills Hub 是一個開源、免費、純靜態的 AI Agent 技能（Skill）目錄。技能按 SKILL.md 規範組織，站台提供分類瀏覽、關鍵字搜尋、標籤篩選、投票收藏與技能詳情，介面支援簡體中文、繁體中文和英語。

站点当前展示 168 个可见技能，覆盖 13 个分类；权威数据源 data/skills-data.json 含 169 条记录，其中 1 条标记为隐藏。数量以该文件为准。

怎样安装和使用一个技能？
把 skills/<技能名>/ 整个目录复制到你的 Agent 技能目录（例如 Claude Code 的 ~/.claude/skills/），技能由 SKILL.md 中的 description 自动触发；也可用 skills-manager 批量管理。
怎樣安裝和使用一個技能？
把 skills/<技能名稱>/ 整個目錄複製到你的 Agent 技能目錄（例如 Claude Code 的 ~/.claude/skills/），技能會由 SKILL.md 中的 description 自動觸發；也可用 skills-manager 批次管理。
技能描述支持哪些语言？
每条技能都有中文描述与英文原文（enDescription），界面可切换简体中文、繁体中文、英语三语；分类名同样提供中英对照。
技能描述支援哪些語言？
每條技能都有中文描述與英文原文（enDescription），介面可切換簡體中文、繁體中文、英語三語；分類名稱同樣提供中英對照。
技能元数据在哪里可以机器读取？
权威数据是站点 /data/skills-data.json，完整可读清单是 /llms-full.txt，供搜索引擎与生成式引擎引用的摘要见 /llms.txt。
技能中繼資料在哪裡可以機器讀取？
權威資料是站台 /data/skills-data.json，完整可讀清單是 /llms-full.txt，供搜尋引擎與生成式引擎引用的摘要見 /llms.txt。
如何分享某次搜索或某个技能？
筛选与搜索结果会同步进 URL hash，例如 #q=wordpress 可直接分享搜索结果，#skill=<技能名> 会自动打开该技能详情。
如何分享某次搜尋或某個技能？
篩選與搜尋結果會同步進 URL hash，例如 #q=wordpress 可直接分享搜尋結果，#skill=<技能名稱> 會自動開啟該技能詳情。
