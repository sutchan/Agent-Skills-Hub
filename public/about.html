关于 Agent Skills Hub

开源 AI Agent 技能目录：按 SKILL.md 规范整理，提供分类浏览、关键词搜索、中英双语描述与一键安装路径；界面支持简体中文、繁体中文与英语，项目整体采用 MIT 协议。 当前展示 168 个可见技能、13 个分类；权威数据共 169 条记录，其中 1 条标记为隐藏。完整清单见 llms-full.txt，机器可读元数据见 skills-data.json。

Agent Skills Hub 是什么？
Agent Skills Hub 是一个开源、免费、纯静态的 AI Agent 技能（Skill）目录。技能按 SKILL.md 规范组织，站点提供分类浏览、关键词搜索、标签筛选、投票收藏与技能详情，界面支持简体中文、繁体中文和英语。
目前收录了多少个技能、多少个分类？
站点当前展示 168 个可见技能，覆盖 13 个分类；权威数据源 data/skills-data.json 含 169 条记录，其中 1 条标记为隐藏。数量以该文件为准。
是否免费？使用什么许可证？
完全免费且开源，项目整体采用 MIT 许可证；各技能自身许可证以其目录内 LICENSE 文件为准。仓库地址 https://github.com/sutchan/Agent-Skills-Hub。
怎样安装和使用一个技能？
把 skills/<技能名>/ 整个目录复制到你的 Agent 技能目录（例如 Claude Code 的 ~/.claude/skills/），技能由 SKILL.md 中的 description 自动触发；也可用 skills-manager 批量管理。
技能描述支持哪些语言？
每条技能都有中文描述与英文原文（enDescription），界面可切换简体中文、繁体中文、英语三语；分类名同样提供中英对照。
技能元数据在哪里可以机器读取？
权威数据是站点 /data/skills-data.json，完整可读清单是 /llms-full.txt，供搜索引擎与生成式引擎引用的摘要见 /llms.txt。
如何分享某次搜索或某个技能？
筛选与搜索结果会同步进 URL hash，例如 #q=wordpress 可直接分享搜索结果，#skill=<技能名> 会自动打开该技能详情。
