组件使用红线

1. 复用 DESIGN.md / tokens.css 的 CSS 变量，禁止硬编码颜色/间距。
1. Reuse DESIGN.md / tokens.css variables; no hardcoded colors/spacing.
  1. 图标统一内联 SVG（lucide 风格），禁止引入其它图标库。
  2. 可交互元素须有 aria-label 或语义角色；弹窗标题用 sr-only。
  3. 动效仅 ~200ms 基准，全局兼容 prefers-reduced-motion。
  4. 业务数据只读来自 data/skills-data.json，不内联假数据。
  5. 样式优先定义在 src/styles/，与令牌同源。
  1. Icons: inline SVG (lucide-style) only; no other icon libs.
  2. Interactive els need aria-label / role; dialog title sr-only.
  3. Motion ~200ms baseline; respect prefers-reduced-motion.
  4. Data read-only from data/skills-data.json; no fake data.
  5. Styles in src/styles/; same source as tokens.
